# BarkLens (바크렌즈) — 강아지 소리·몸짓 패턴 시각화 · 해석 앱

강아지 소리를 사람의 말로 "번역"하는 대신, **소리와 몸짓의 패턴을 보이게 만들고 동물행동학 논문의 규칙으로 상황을 읽어 주는** 앱의 기획과 샘플 구현입니다.

```
dog-language-app/
├── README.md
├── docs/
│   ├── 01_기획서.md            # 서비스 기획서 (시장·근거·기능·UX·데이터/AI·기술·사업·로드맵·리스크)
│   ├── 02_리서치_논문정리.md    # 40여 편 논문 + 데이터셋 + 경쟁/시장 정리 (DOI 링크)
│   └── 03_발표요약.md          # 12장 발표 원고
└── app/                        # 샘플 앱 (순수 HTML/CSS/JS, 빌드 없음)
    ├── index.html              # 5탭 UI: 듣기 · 몸짓 · 기록 · 근거 · 설정
    ├── styles.css              # 디자인 토큰(라이트/다크), 레이아웃
    ├── dsp.js                  # 신호처리 + 해석 엔진 (FFT, NSDF 피치, 이벤트 검출, 3축 지문, 상황 점수)
    ├── knowledge.js            # 몸짓 단서 25개, 근거 논문, 데이터셋
    ├── app.js                  # 마이크/파일/데모 입력, 스펙트로그램, 판독 카드, 기록(localStorage)
    └── test/dsp.test.js        # Node 검증 (합성 짖음 5종 → 기대 상황)
```

## 실행

```bash
# 1) 엔진 검증 (Node 18+)
node dog-language-app/app/test/dsp.test.js

# 2) 앱 실행 — 정적 서버로 열기 (마이크는 localhost/https에서만 동작)
npx serve dog-language-app/app        # 또는
python3 -m http.server -d dog-language-app/app 8080
```

`index.html`을 파일로 직접 열어도 데모·파일 분석은 동작합니다. 실제 마이크 듣기는 `http://localhost` 또는 `https` 환경이 필요합니다.

## 샘플 앱이 하는 일

1. **듣기**: 마이크(또는 녹음 파일·데모 합성음)에서 짖음을 자동으로 잘라내고, 150 Hz–8 kHz 로그 축 스펙트로그램과 6초 포락선으로 보여 줍니다.
2. **3축 지문**: 음높이(F0, 몸집·개체 기준 대비) · 음색(조화도) · 리듬(짖음 간격)을 슬라이더와 레이더로 표시합니다.
3. **상황 읽기**: 외로움·경계·놀이·요구·두려움 5가지 확률과 확신도, 그리고 "왜 이렇게 읽었나"(특징값 → 문헌 규칙)를 보여 줍니다. 소리 종류(짖음·깽·낑낑·으르렁·하울링)도 구분합니다.
4. **태그·기록**: 실제 상황을 태그하면 기록에 쌓이고, 7일 상황별 막대와 태그 일치율을 봅니다. 짖음 10회 이상이면 우리 강아지 기준 음역을 자동 학습합니다.
5. **몸짓**: 꼬리·귀·얼굴·자세 단서 25개를 체크하면 정서가·각성 평면과 대응 안내를 줍니다.
6. **근거**: 앱 규칙의 출처 논문(DOI)과 공개 데이터셋 목록.

## 한계 (의도된 것)

- "번역"이 아니라 확률과 근거를 보여 주는 렌즈입니다. 의료·행동 진단이 아닙니다.
- 브라우저 로컬에만 저장하며 소리는 어디에도 전송하지 않습니다.
