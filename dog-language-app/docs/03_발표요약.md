# BarkLens 발표 요약 (12장)

> 기획서(01)와 리서치(02)를 12장 슬라이드 분량으로 압축한 발표 원고. 각 장은 "제목 + 말할 것 3~5개".

---

### 1. 문제
- 반려인 1,546만 명, 반려가구 591만(26.7%). 시장은 2032년 21조 원 전망.
- 보호자의 질문은 하나로 모인다: **"얘가 지금 왜 이러는 거지?"**
- 짖음·낑낑·으르렁, 꼬리·귀·표정. 신호는 넘치는데 읽는 법이 없다.

### 2. 번역은 안 된다, 그런데
- 짖음은 단어가 아니라 **등급 신호**다 (Yin & McCowan 2004).
- 같은 소리도 상황에 따라 뜻이 다르다. "번역기" 마케팅(90%, 81.5%)은 과학이 보여 준 것과 어긋난다.
- 그러나 **거꾸로는 된다**: 소리·몸짓의 패턴을 사람이 알아볼 수 있는 형태로 바꾸는 것.

### 3. 20년 연구가 말하는 세 개의 축
- **음높이**: 낮으면 경계·공격, 높으면 놀이·두려움·외로움.
- **음색**: 거칠면 방해·경계, 맑으면 놀이·고립.
- **리듬**: 빠르게 몰아치면 공격, 띄엄띄엄이면 두려움·절망, 빠르고 높으면 놀이.
- 출처: Pongrácz 2005/2006, Yin & McCowan 2004, Faragó 2014. 시각장애인도 같은 규칙으로 맞춘다 (Molnár 2010).

### 4. 기계는 얼마나 맞추나
- 6상황 43% (Molnár 2008) → 7상황 55.5%, 성별 85%, 나이 80% (Larrañaga 2015) → 딥러닝으로 상회 (Gómez-Armenta 2024, 19,643회).
- 사람 음성으로 학습한 Wav2Vec2가 개 전용 모델보다 낫다 (Abzaliev 2024).
- 2025년 공개 데이터셋 등장: Barkopedia(IJCAI), EmotionalCanines(ACM MM).

### 5. 몸짓도 근거가 있다
- 꼬리 오른쪽 편향=접근, 왼쪽=회피. 개도 이를 읽는다 (Quaranta 2007; Siniscalchi 2013).
- DogFACS: 귀 앞으로 모음=긍정 기대, 코 핥기·귀 납작·눈 깜빡임=좌절 (Bremhorst 2019).
- 단, **단일 단서로는 진단 불가** → 조합해야 한다 (Bremhorst 2022).

### 6. 제품 정의
- **BarkLens = 강아지 소리·몸짓의 렌즈.**
- 보이게(스펙트로그램·3축 지문) → 읽히게(상황 확률 5개 + 근거) → 배우게(개체 기준선) → 나아지게(대응 팁).
- 원칙: 투명성 · 확률 표기 · 의인화 금지 · 온디바이스 · 복지 우선.

### 7. 샘플 앱 (오늘 시연)
- 듣기: 실시간 검출, 로그 주파수 스펙트로그램, 3축 슬라이더+레이더, 상황 막대, "왜 이렇게 읽었나", 태그.
- 몸짓: 25개 단서 체크 → 정서가·각성 평면.
- 기록: 7일 상황별 스택 막대, 보호자 태그 일치율.
- 근거: 40여 편 논문 카드(DOI), 데이터셋.
- 데모 5종(초인종·공놀이·혼자·낑낑·으르렁)으로 엔진 검증 완료(13개 자동 검사 통과).

### 8. 데이터와 AI 로드맵
- v0 규칙 엔진(지금) → v0.5 YAMNet 검출 → v1 파운데이션 임베딩 + 상황 분류/각성·정서가 회귀 → v1.5 개체 적응 → v2 카메라 멀티모달.
- 데이터: 공개셋 부트스트랩 + 앱 내 "실제 상황은?" 태그로 국내 견종 데이터 구축(6개월 2,000마리 5만 이벤트).
- 지표: macro-F1 ≥ 0.6, 보호자 일치 ≥ 70%, 온디바이스 300 ms.

### 9. 경쟁과 차별화
- Petpuls(목걸이·5감정·하드웨어 필수), Traini(앱·12감정·과잉 확신 비판), Baidu(특허).
- BarkLens: 근거 공개 + 확률 + 개체 학습 + 몸짓 조합 + 온디바이스. "정직한 렌즈"가 브랜드.

### 10. 비즈니스
- 무료: 실시간 판독·몸짓·7일 기록. Pro: 부재 모니터링·리포트·훈련사 공유·다견.
- B2B: 훈련사/행동 수의사 대시보드, 보험·시터·유치원 API, 하드웨어 SDK.
- KPI: 일일 판독 수, 태그율, 일치율, D30, Pro 전환.

### 11. 로드맵
- M1 PWA MVP(1–2개월) → M2 데이터(3–4) → M3 모델 v1(5–6) → M4 부재 모드·Pro(6–8) → M5 개체 적응·B2B(9–12) → M6 멀티모달.

### 12. 리스크와 결정 요청
- 리스크: 과잉 주장, 오판 복지 위험, 견종 편향, 프라이버시, 오탐, 빅테크.
- 결정 요청: ① PWA 우선 ② 소형견 집중 ③ 태그 인센티브 ④ 하드웨어는 파트너.
- 다음 액션: 샘플 앱을 실제 강아지 소리로 1주 테스트 → 규칙 보정 → M1 착수.
