# 「별이 되어줘」 UI 재설계 v2 — "백스테이지 / 온스테이지"

- 문서 버전: 2.0 (2026-09-05)
- 설계: Fable 5.1 / 구현: Opus 5
- 이 문서는 GDD 12·13절과 TECH_SPEC 6절의 UI 부분을 **대체**한다. 엔진·데이터·타입(`src/game/idol/engine`, `data`, `types.ts`)은 그대로 쓴다.

---

## 0. 왜 다시 만드는가

v1의 문제는 셋이다.
1. **아이돌이 주인공이 아니다.** 초상이 124px 상자에 갇혀 있고 화면의 대부분이 숫자 카드다. 아이돌 육성 게임의 재미는 "내가 키운 애가 점점 멋있어지는 걸 보는 것"인데, 그걸 볼 자리가 없다.
2. **장르의 얼굴이 없다.** 어두운 남색 + 보라 포인트 + 둥근 카드는 어떤 관리 도구에나 있는 화면이다. K-pop의 시각 언어(포토카드, 팬 앱의 버블 메시지, 음악방송 1위 자막, 응원봉 색, 시상식 조명)가 하나도 없다.
3. **이미지가 들어와도 좋아지지 않는다.** 이미지 자리가 작고 잘리며, 이미지를 모을 이유가 없다.

v2의 답: **화면의 절반을 아이돌에게 준다. 관리 화면은 팬 앱처럼 밝고, 무대 화면은 공연장처럼 어둡다. 이미지는 포토카드로 수집된다.**

## 1. 비주얼 아이덴티티

### 1.1 두 세계: 백스테이지와 온스테이지
게임의 시간은 두 종류다. 매니저가 스케줄을 짜고 정산을 보는 **낮의 시간(백스테이지)** 과, 하람이 무대에 서는 **밤의 시간(온스테이지)**. UI 도 그렇게 나눈다.

| | 백스테이지 (관리) | 온스테이지 (무대) |
|---|---|---|
| 화면 | 캐릭터 생성, 메인(계획), 진행, 월말 리포트, 앨범, 저장 메뉴 | 타이틀, 데뷔 평가, 컴백 결과, 시상식, 엔딩 |
| 바탕 | 라일락 기운이 도는 웜 화이트 | 자정의 인디고, 조명 빔 |
| 느낌 | 팬 앱(위버스·버블)과 플래너 앱 | 음악방송·시상식 무대 |
| 이미지 | 밝은 바탕 위 포토카드 | 전면(full-bleed) 일러스트 + 스크림 |

전환은 화면 단위로 일어나며(페이지 배경이 통째로 바뀜), 두 세계를 잇는 것은 **하람의 공식색 코랄**뿐이다.

### 1.2 색 토큰 (`src/app/idol/idol.css` 의 `:root`)

하람의 응원봉 색 = **코랄 #FF6B8A**. 모든 강조는 이 색 하나로 한다. 금색은 "수상·1위"의 의미색으로만, 민트는 "상승"의 의미색으로만 쓴다(포인트로 쓰지 않는다).

```css
/* 백스테이지 (기본) */
--bg: #FBF8FC;           /* 라일락 기운 웜 화이트 */
--surface: #FFFFFF;
--surface-2: #F3EEF6;    /* 라일락 그레이, 비활성·구분 */
--ink: #1E1A2E;
--ink-2: #5B5670;        /* 보조 텍스트 */
--ink-3: #726C85;        /* 캡션·비활성 — 4.7:1 (초안 #9A94B0 은 2.8:1 로 기준 미달이라 구현 시 조정) */
--on-accent: #FFFFFF;    /* 코랄 채움 위 글자 */
--on-media: #FFFFFF;     /* 이미지 스크림 위 글자 */
--line: #E7E0EE;
--accent: #FF6B8A;       /* 하람 공식색 */
--accent-ink: #D6335A;   /* 밝은 바탕 위 텍스트용 코랄 (대비 확보) */
--accent-soft: #FFE3E9;
--good: #1FA97A;         /* 상승 (의미색) */
--bad: #E5484D;          /* 하락·위험 */
--warn: #E8961E;
--gold: #D9A93A;         /* 수상·1위 (의미색) */
--shadow: 0 10px 30px rgba(60, 30, 80, 0.10);

/* 온스테이지 — 무대 화면의 루트 요소에 .stage 를 붙여 토큰을 덮어쓴다 */
.stage {
  --bg: #0F0C24;
  --surface: rgba(255,255,255,0.06);
  --surface-2: rgba(255,255,255,0.10);
  --ink: #F6F2FF;
  --ink-2: #B9B2D6;
  --ink-3: #8A83AD;      /* 5.4:1 (초안 #6F6890 은 3.7:1) */
  --line: rgba(255,255,255,0.12);
  --accent-ink: #FF8FA6;
  --accent-soft: rgba(255,107,138,0.18);
  --gold: #F5C451;
  --shadow: 0 0 40px rgba(255,107,138,0.25);
}

/* 홀로그램 (포토카드 희귀 프레임·잠긴 카드 뒷면) */
--holo: conic-gradient(from 200deg, #FF9BB3, #C9A7FF, #9EF0E1, #FFE58A, #FF9BB3);
```

컴포넌트는 반드시 토큰만 쓴다(리터럴 색 금지). 그래야 같은 컴포넌트가 두 세계에서 모두 맞는다. 이 게임은 의도적으로 라이트/다크를 "화면 종류"로 정하므로 OS 테마는 따르지 않는다(`color-scheme` 은 백스테이지 light, `.stage` 안에서 dark).

### 1.3 타이포그래피
- **디스플레이: Black Han Sans** — 무대의 큰 글자 전용. "1위", "데뷔", "대상", 점수, 엔딩 제목, 타이틀 워드마크. 40~72px, 한 화면에 한 덩어리만.
- **UI·본문: Gothic A1** — 400 / 500 / 700 / 800. 스케일 11 · 12 · 13 · 15 · 17 · 20 · 24 · 32. 본문 15/1.6, 라벨 12/1.3, 숫자는 `font-variant-numeric: tabular-nums`.
- 폴백: `"Apple SD Gothic Neo", "Malgun Gothic", sans-serif`.
- 로딩: Next 앱은 `next/font/google` (`Gothic_A1` 400·500·700·800, `Black_Han_Sans` 400) 으로 `--font-body`, `--font-display` 변수를 만든다. 단일 HTML 빌드는 `tools/idol-standalone/index.html` 과 `inline.mjs` 출력에 Google Fonts `<link>` 를 넣고 `entry.css` 가 같은 변수를 선언한다. 컴포넌트는 변수만 참조한다 (`.idol-root { font-family: var(--font-body), … }`, `.display { font-family: var(--font-display), … }`).

### 1.4 형태 언어
- 포토카드: 3:4, 반지름 14px, 2px 프레임(단계별), 하단 라벨 띠.
- 카드(일반): 반지름 20px, 테두리 1px `--line`, 그림자는 **떠 있어야 하는 것 하나**에만(메인의 스탯 글래스 카드, 바텀시트).
- 버튼: 높이 52px(기본)/44px(작은), 반지름 14px, 주요 CTA 는 코랄 채움 + 흰 글자 800.
- 칩/필: 반지름 999px, 높이 26px, 12px 700.
- 아이콘: 활동 아이콘은 이모지를 40px 원(분류별 연한 배경) 안에 넣어 통일한다. 나머지 UI 아이콘은 인라인 SVG 선 아이콘(1.75px, 라운드 캡) 12종 이내: 메뉴, 닫기, 뒤로, 저장, 앨범, 설정, 더하기, 체크, 경고, 별, 하트, 재생.
- 유리(glass): 온스테이지와 메인 히어로 위의 카드는 `backdrop-filter: blur(16px)` + `--surface`.

### 1.5 모션 (전부 `prefers-reduced-motion` 존중)
- 숫자 카운트업 400ms (점수·팬·순위).
- 주차 카드 순차 등장 (translateY 12px → 0, 240ms, 120ms 간격).
- 무대 화면 진입: 조명 빔이 0.8s 동안 벌어짐(opacity·scale).
- 1위·대상·S 엔딩: 컨페티 캔버스 2.5s (Canvas 2D, 파티클 120개, 코랄·골드·화이트).
- 엔딩 에필로그: 문장 단위 페이드인 (타자기 효과는 쓰지 않는다 — 읽기 속도를 강제하지 않기 위해).
- 그 외 hover/press 는 120ms 색·그림자 전환만.

## 2. 이미지 시스템: 포토카드

### 2.1 원칙
이미지는 UI 의 장식이 아니라 **보상**이다. 모든 이미지 에셋은 앨범의 카드 한 장에 대응하고, 게임 안에서 처음 마주치는 순간 "획득"된다.

### 2.2 카드 41장

| 세트 | 카드 id | 장수 | 획득 조건 | 프레임 |
|---|---|---|---|---|
| 연습생 | `char:trainee_{emotion}` | 6 | 데뷔 전 히어로에 그 감정이 처음 표시될 때 | 기본 (`--line`) |
| 신인 | `char:rookie_{emotion}` | 6 | 데뷔 후(rookie) 히어로에 처음 표시될 때 | 실버 (#C9CCD6) |
| 스타 | `char:star_{emotion}` | 6 | rising 이상에서 처음 표시될 때 | 골드 (`--gold`) |
| 순간(CG) | `cg:{id}` | 8 | `debut_showcase`·`first_win`·`award_grand_prize`·`world_tour`·`bond_promise` = `state.flags.cg_*`; `scandal_news` = 루머/열애설 이벤트 표시 시; `burnout_night` = E31 표시 시; `comeback_stage` = 첫 컴백 결과 화면 | 홀로 |
| 엔딩 | `ending:{id}` | 15 | 엔딩 도달 | 홀로 |

- 저장: `save.ts` 에 `loadAlbum(): string[]`, `unlockCards(ids: string[]): string[]`(새로 열린 것만 반환) 추가. 키 `idolboy.album`. 엔진은 건드리지 않는다.
- 새 카드가 열리면 화면 하단에 **"포토카드 획득"** 토스트(카드 썸네일 + 이름, 2.4s). 월말 리포트와 엔딩에서는 토스트 대신 리포트 안 "이달의 카드" 섹션에 모아 보여준다.
- 카드 앞면 = 해당 이미지(없으면 폴백), 뒷면(잠김) = 홀로 그라데이션 위에 별 워드마크와 힌트 한 줄.

### 2.3 이미지가 없을 때의 폴백 (이미지가 들어오기 전에도 "완성된 화면"이어야 한다)
- **포트레이트 폴백**: 이니셜 상자 금지. 상반신 **실루엣 SVG**(머리·목·어깨의 단순한 곡선 4~6개, 앞머리 한 가닥) 를 단계별 색으로 채우고, 뒤에 스포트라이트 원뿔 그라데이션, 오른쪽 아래에 감정 아이콘 배지. 실루엣은 컴포넌트 하나(`Silhouette`)로 두고 크기만 바꿔 쓴다.
- **배경 폴백**: 장면별 그라데이션 + 단순 모티프. `practice_room` 거울 격자선, `stage_music_show`/`concert_arena`/`award_stage` 조명 빔, `dorm` 창문 사각형과 따뜻한 빛, 나머지는 2색 그라데이션. CSS 만으로.
- **타이틀 키비주얼 폴백**: Canvas 별 입자 + 코랄 조명 빔 두 줄기.
- 잠긴 카드·엔딩 미획득은 이미지를 요청하지 않는다(404 방지).

## 3. 화면 설계 (모바일 세로 기준 폭 390~480px)

### 3.1 타이틀 (온스테이지)
```
┌──────────────────────────────┐
│ [키비주얼 전면, 위 2/3]         │  ← 하단으로 갈수록 --bg 로 스크림
│                              │
│         별이 되어줘             │  ← Black Han Sans 44px
│      남자 아이돌 키우기          │  ← Gothic A1 13px, 자간 0.2em, --accent-ink
│  ┌ 이어하기 ───────────────┐   │  ← 자동 저장이 있을 때만. 작은 포토카드 + 이름·개월·팬
│  │ [카드] 하람 · 2년차 3월  │   │
│  └──────────────────────┘   │
│  [      새 게임 ▶      ]     │  ← 코랄 CTA
│   불러오기     포토카드 앨범    │  ← 텍스트 버튼 2개
└──────────────────────────────┘
```
- 이어하기가 있으면 그것이 첫 번째 버튼이다(돌아온 플레이어가 가장 자주 누른다).

### 3.2 캐릭터 생성 (백스테이지) — "연습생 계약서"
세 단계를 한 페이지에서 세로로 진행하되, 위 단계가 끝나야 다음 단계가 펼쳐진다.
1. **계약서 카드**: "루미너스 엔터테인먼트 연습생 계약서" 제목, 이름 입력은 서명란처럼(밑줄, 큰 글자 24px). 기본값 "하람".
2. **출신 5택**: 가로 스크롤 카드(폭 220px). 카드마다 출신 이름, 한 줄 설명, **6각 레이더 미니 차트**(초기 능력치), 재능 배지("비주얼 재능 ×1.4"). 선택 시 코랄 테두리.
3. **성격 4택**: 칩 4개 + 선택한 칩의 효과 요약 한 줄.
- 하단 고정: 미리보기 **포토카드**(연습생 기본 표정, 폴백 실루엣) + 이름 + "계약 체결" CTA.

### 3.3 메인 (백스테이지) — 이미지가 주인공
```
┌──────────────────────────────┐
│ 1년차 3월 · 연습생   💰250만 👥3.2천 ≡ │  ← 상태바 44px, 팬은 formatFans
├──────────────────────────────┤
│ ┌ 장면 배경 (페이즈별) ┐         │
│ │                        │      │
│ │      [하람 상반신]        │      │  ← 히어로 높이 360px, 초상은 하단 정렬
│ │                        │      │
│ │ ○하람 오후 9:12          │      │  ← 버블 메시지 (팬 앱 DM 스타일), 좌하단
│ │ ┃ 매니저님, 이번 달은     │      │
│ │ ┃ 보컬 좀 더 하고 싶어요  │      │
│ └────────────────────────┘      │
│      ┌ 글래스 카드 ────────────┐ │  ← 히어로 하단에 24px 겹쳐 떠 있음
│      │ [레이더 6각]  체력 ◔ 78   │ │     레이더 110px + 링 게이지 3개(체력·스트레스·호감도)
│      │              스트레스 ◔35 │ │     + 평판 칩. 탭하면 상세 시트(바·숫자·재능 힌트)
│      │              호감도 ◔42  │ │
│      └─────────────────────────┘ │
│ 이번 달 스케줄              모두 같은 활동 │
│ ┌1주┐ ┌2주┐ ┌3주┐ ┌4주┐          │  ← 플래너 카드 4개 (각 폭 1/4, 높이 96)
│ │🎤 │ │🎤 │ │ + │ │ + │          │     비어 있으면 점선 + "+"
│ │보컬│ │보컬│ │   │ │   │          │
│ └───┘ └───┘ └───┘ └───┘          │
│ 예상: 💰−60만  체력 −25  스트레스 +8│  ← 필 3개, 문제 있으면 경고 필(코랄)
│ [        이번 달 진행 ▶        ] │  ← 코랄 CTA 56px
│  데뷔 평가 신청 · 트레이너 ★2 · 앨범  │  ← 보조 액션(텍스트 버튼)
└──────────────────────────────┘
```
- 장면 배경: trainee → `practice_room`, rookie → `office`, rising → `recording_studio`, star → `concert_arena`.
- 초상: `portraitSrc(stage, emotion)`, `object-fit: cover; object-position: top`, 폭 최대 300px, 하단 정렬. 폴백은 실루엣.
- 버블: 아바타(초상 얼굴 크롭 32px 원, 폴백 실루엣) + 이름 + 시각(월에 따라 결정적으로 생성, 예: `오후 ${7 + month % 3}:${(month * 17) % 60}`) + 말풍선(흰 바탕, 꼬리 왼쪽). 텍스트는 `getIdolLine`.
- 레이더: SVG 6각, 축 라벨 6개(보컬·댄스·랩·비주얼·예능감·연기), 채움 코랄 24% + 선 코랄. 100 기준 격자 2단(50·100).
- 링 게이지: 반지름 18, 두께 4. 체력은 `--good`, 스트레스는 70 이상 `--bad` 아니면 `--warn`, 호감도는 `--accent`.
- 플래너 카드: 활동 아이콘 원 + 라벨 2줄. 탭 → 활동 시트. 길게 누르기/카드의 "×" 는 두지 않는다(시트 안 "이 주차 비우기").

### 3.4 활동 시트 (바텀시트, 백스테이지)
- 상단 손잡이, 제목 "N주차 활동", 분류 탭 4개(훈련 / 알바·활동 / 홍보 / 휴식) — 선택 탭은 코랄 밑줄.
- 행: 아이콘 원 · 이름(15/700) · 설명(12, `--ink-2`) · 오른쪽에 효과 필(💰−30 · 체력 −15 · 보컬 ↑). 불가하면 회색 + 사유.
- 하단: "이 주차 비우기", "4주 모두 이 활동으로".

### 3.5 진행 (백스테이지) — 주간 타임라인
- 히어로는 그대로 두되(표정은 주차 결과에 따라 갱신), 아래 영역이 **주차 카드 4장**으로 바뀐다. 각 카드는 순서대로 뒤집히며 활동 아이콘, 한 줄 결과, 델타 칩(보컬 +3.2 / 체력 −15 …, 상승 `--good` 하락 `--bad`).
- 속도 토글(보통/빠르게)은 우상단 작은 칩.
- 이벤트가 나면 **장면 뷰**(3.6)로 전환하고 끝나면 타임라인으로 돌아온다.

### 3.6 이벤트 장면 (비주얼 노벨식, 배경에 따라 온/백스테이지 자동)
```
┌──────────────────────────────┐
│ [배경 전면]                     │
│                 [하람 상반신]   │  ← 오른쪽 하단 정렬, 높이 60%
│ ┌──────────────────────────┐ │
│ │ 하람 · 악플               │ │  ← 이름 태그 + 이벤트 제목
│ │ 댓글 창에 외모를 두고 …     │ │  ← 본문 15/1.7, 최대 6줄, 넘치면 내부 스크롤
│ │ [ 신경 쓰지 말라고 한다 ]   │ │  ← 선택지 세로 버튼, 힌트는 작은 글씨
│ │ [ 끝까지 들어준다 ]        │ │
│ └──────────────────────────┘ │
└──────────────────────────────┘
```
- 선택 후 결과 문구를 같은 박스에 표시하고 [계속]. 판정(check) 결과는 "성공/실패" 칩으로 표시.
- 배경 id 가 무대 계열(`stage_music_show`, `award_stage`, `concert_arena`)이면 `.stage` 토큰.

### 3.7 월말 리포트 (백스테이지) — "이달의 리포트"
- 헤더: "1년차 3월 리포트" 24/800 + 오른쪽에 이달의 포토카드(있으면 새로 획득한 것, 없으면 현재 표정).
- 섹션 1 **레이더 전/후 겹침** (전: `--ink-3` 점선, 후: 코랄) + 오른쪽에 변화 큰 순 3개 칩.
- 섹션 2 컨디션·사회: 4행(체력·스트레스·호감도·평판) 전→후 + 델타.
- 섹션 3 정산: 항목 리스트(수입 `--good`, 지출 `--bad`), 합계.
- 섹션 4 공지(부상·페이즈 전환 등) 칩.
- 섹션 5 버블 메시지(하람의 한마디).
- 섹션 6 "이달의 카드"(새로 열린 카드가 있으면).
- 하단 CTA "다음 달로".

### 3.8 데뷔 평가 · 컴백 · 시상식 (온스테이지)
- 공통: `.stage` 배경 + `StageBackdrop`(조명 빔 3줄기 + 입자). 상단에 작은 라벨(예: "데뷔 평가 · 1년차 9월").
- **데뷔 평가**: 점수 카운트업 64px 디스플레이 → "합격"/"불합격" 디스플레이 40px(합격 골드·불합격 `--ink-2`) → 심사평 문구 → [확인]. 합격이면 컨페티.
- **컴백**: 1단계 선택 — 콘셉트 5장은 **앨범 재킷 카드**(3:4, 콘셉트별 그라데이션 + 이름·한 줄 무드), 포커스 3버튼(보컬·댄스·랩). [발매] CTA. 2단계 결과 — "차트 성적" 라벨, 순위 디스플레이("1위" 골드 / "TOP 10" / "TOP 50" / "진입 실패"), 점수, 팬·자금 델타 칩, 적성 힌트 문장. 1위면 컨페티 + `first_win` CG 카드 획득 연출.
- **시상식**: 수상 목록을 트로피 카드로 세로 나열(신인상·본상·대상·인기상, 대상은 골드 프레임). 없으면 "올해는 객석에서 박수만" 한 줄.

### 3.9 엔딩 (온스테이지)
- 엔딩 일러스트 전면(폴백: 장면 그라데이션 + 실루엣) → 등급 배지(S/A/B/C/D) + 제목 디스플레이 40px → 에필로그 문장별 페이드인 → 최종 스탯 요약(레이더 + 팬·수상) → "포토카드 획득: {엔딩 제목}" 카드 뒤집힘 → [앨범 보기] [타이틀로].

### 3.10 포토카드 앨범 (백스테이지, `/idol/album`)
- 상단: "포토카드 앨범 12/41", 세트 탭(연습생 · 신인 · 스타 · 순간 · 엔딩).
- 3열 그리드(3:4 카드). 잠긴 카드는 홀로 뒷면 + 힌트(탭하면 힌트 전체).
- 카드 탭 → 전체 화면 뷰어(이미지 크게, 이름, 획득일, 좌우 스와이프).
- 엔딩 탭이 기존 "엔딩 도감"을 흡수한다(`/idol/endings` 는 앨범의 엔딩 탭으로 리다이렉트).

### 3.11 저장 메뉴 (바텀시트)
- 슬롯 3개를 **포토카드 썸네일 + 이름 · 개월 · 팬 · 저장 시각** 행으로. 덮어쓰기/삭제 확인 다이얼로그 유지. 속도 설정, 앨범, 타이틀로.

## 5. 접근성·품질 기준
- 텍스트 대비 4.5:1 이상 (백스테이지 `--ink-2` on `--bg`, 온스테이지 `--ink-2` on `--bg` 모두 확인). 코랄 위 흰 글자는 800 웨이트 15px 이상에서만.
- 터치 타깃 44px 이상. 포커스 링 코랄 2px.
- 가로 스크롤 금지(모든 화면 `scrollWidth ≤ viewport`). 긴 텍스트는 줄바꿈 또는 내부 스크롤.
- 이미지 0장 상태에서도 모든 화면이 "완성된 화면"으로 보여야 한다(폴백 규칙 2.3).
- 폰트가 로드되기 전에도 레이아웃이 흔들리지 않도록 `font-display: swap` + 폴백 스택의 폭이 비슷한 Gothic 계열.
