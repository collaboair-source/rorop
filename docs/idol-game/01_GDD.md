|---|---|

| 플랫폼 | 웹 브라우저 (모바일 세로 화면 우선, 데스크톱 호환) |

| 참고 구조 | 딸키우기류의 "월 단위 스케줄 배치 → 능력치 성장 → 랜덤 이벤트 → 엔딩 판정" 루프를 그대로 차용. 여기에 아이돌 장르 고유의 **데뷔 평가 / 컴백 / 시상식 / 팬 수 / 스캔들** 축을 추가 |
| 언어 | 한국어 UI·텍스트 |
| 저장 | 브라우저 로컬 저장 (자동 저장 1 + 수동 슬롯 3), 엔딩 도감 |

### 1.1 디자인 필러 (설계 원칙)
1. **선택이 곧 성장** — 매달 4개의 주간 슬롯에 무엇을 넣느냐가 능력치·체력·스트레스·돈을 모두 흔든다. 정답 빌드는 없고 트레이드오프만 있다.
2. **사람을 키운다** — 숫자만 오르는 게 아니라 하람(아이돌)이 매달 말을 걸고, 스트레스와 호감도에 따라 태도가 달라진다.
3. **아이돌 커리어의 리듬** — 연습생 → 데뷔 평가 → 컴백(4개월 주기) → 연말 시상식의 리듬이 게임의 중반 이후를 끌고 간다.
4. **짧고 다회차** — 한 회차 1시간 안팎. 엔딩 도감이 다회차 동기를 만든다.

## 2. 세계관과 캐릭터

### 2.1 배경
- **루미너스 엔터테인먼트**: 직원 6명의 소규모 기획사. 사옥은 서울 마포구 골목의 3층 건물(1층 연습실, 2층 사무실, 3층 숙소).
- **플레이어**: 갓 입사한 신입 매니저. 대표에게 "연습생 한 명, 3년. 데뷔 못 시키면 둘 다 끝"이라는 미션을 받는다. 이름은 등장하지 않고 하람은 플레이어를 "매니저님"이라고 부른다.
- **시간**: 게임 시작 = 1년차 1월(18세). 36개월 후(21세) 종료. 연말 시상식은 12·24·36개월차.

### 2.2 아이돌 — 서하람 (기본 이름, 변경 가능)
- 18세, 178cm. 검은 머리(앞머리 살짝 내림), 진갈색 눈, 왼쪽 눈 밑 작은 점(시그니처), 왼쪽 귀 은색 이어링, 웃으면 한쪽 보조개.
- 외형은 이미지 에셋에 고정되고, 플레이어는 이름·출신·성격만 고른다.
- 포트레이트 단계: `trainee`(연습복) → `rookie`(첫 무대 의상) → `star`(전성기 의상). 단계 전환 규칙은 8.6절.

## 3. 코어 루프

```
[월 계획]  주간 슬롯 4개에 활동 배치 (자금·조건 확인) ─┐
     │  (데뷔 전: "데뷔 평가 신청" 버튼 / 트레이너 업그레이드)   │
     ▼                                                        │
[주차 해결] 1주차→4주차 순서로 활동 실행                        │
     │   각 주차 결과 로그 + 확률/조건 이벤트 발생 → 선택지       │
     ▼                                                        │
[월말 리포트] 능력치 변화, 수입/지출, 팬 변화, 하람의 한마디      │
     │                                                        │
     ├─ (데뷔 후 컴백 달) → [컴백] 콘셉트·타이틀 포커스 선택 → 차트 결과
     ├─ (12/24/36개월차, 데뷔 상태) → [연말 시상식]
     ├─ (24개월차 미데뷔) → [계약 종료 엔딩]
     └─ (36개월차) → [엔딩 판정]  ─── 그 외 → 다음 달 [월 계획] ──┘
```

- 1턴 = 1개월 = 4주 슬롯. 총 36턴 = 144 슬롯.
- 각 슬롯의 활동은 즉시 반영되며, 주차 사이에 이벤트가 끼어들 수 있다(선택지 팝업).
- 플레이어의 조작은 **계획 → 실행 → 선택지 응답 → 확인**뿐이다. 실시간 요소 없음.

### 5.1 팬 증가 공식 (fansFormula, 주 1회 실행 기준)
`rng` = 0.8~1.2 균등 난수, `phaseMul` = trainee 1.0 / rookie 3.0 / rising 5.0 / star 8.0.

| formula | 팬 증가량 |
|---|---|
| `busking` | round((max(보컬,댄스)×8 + 비주얼×4) × phaseMul × rng) |
| `sns` | round((비주얼×6 + 예능감×6 + 100) × (1 + log10(팬+10)/4) × rng) |
| `model` | round(비주얼×4 × phaseMul × rng) |
| `music_show` | round((max(2000, 팬×0.04×activeMul) + perf×30) × rng), perf = (보컬+댄스+랩)/3×0.6 + 비주얼×0.4, activeMul = 마지막 컴백 후 2개월 이내면 1.0, 아니면 0.4 |
| `fansign` | round(max(1000, 팬×0.02) × rng) |
| `variety_show` | round(max(3000, 팬×0.03) × (예능감/50) × rng) |
| `event_stage` | round(max(500, 팬×0.005) × rng) |

모든 팬 증가에 성격 `fansMul` 적용.

## 6. 성장 공식

한 주 훈련의 능력치 상승량:

```
gain = BASE(4) × talent × trainerMul × dim(skill) × condMul × personalityMul × boostMul × rng(0.85~1.15) × skillGain(활동표의 G 배수)
```

| 항목 | 값 |
|---|---|
| `talent` | 출신 재능 배수 0.8~1.4 |
| `trainerMul` | 트레이너 등급 1.0 / 1.25 / 1.5 (자율 연습에는 미적용) |
| `dim(skill)` | max(0.08, 1 − 현재치/120) — 고레벨일수록 감쇠 |
| `condMul` | 체력 < 30 → ×0.5, 스트레스 ≥ 70 → ×0.7, 부상 → ×0.5 (중복 적용) |
| `personalityMul` | 성격표 "훈련 효과" |
| `boostMul` | 라이벌 이벤트 등으로 `flags.training_boost_until ≥ 현재 월`이면 ×1.15 |
| 최소값 | 훈련 활동이면 최소 +0.5 |
| 상한 | 100 |

체력 소모 = 활동표 값 × (부상 시 1.3). 스트레스 증가 = 활동표 값 × 성격 `stressMul`(감소는 `restMul` 적용).

**밸런스 목표**: 한 능력치를 15→90까지 올리는 데 기본 트레이너로 약 27회의 레슨(자율 연습만이면 약 45회). 144슬롯 중 휴식·알바를 빼면 실제 훈련 가능 슬롯은 약 90~100개 → "3개 능력치 90 도달"은 가능하지만 "6개 모두 90"은 불가능해야 한다.

### 7.3 자금 부족

- 연습생 기간 월말 자금 < 30 이면 [생활고 이벤트 E33]에서 가불 가능.

## 8. 커리어

### 8.1 커리어 페이즈

| phase | 조건 |
|---|---|
| `trainee` | 데뷔 전 |
| `rookie` | 데뷔 후, 팬 < 300,000 |
| `rising` | 팬 300,000 ~ 1,499,999 |
| `star` | 팬 ≥ 1,500,000 |

월말마다 재계산. 활동 해금과 팬 공식 배수에 사용.

### 8.2 데뷔 평가
- 신청 조건: 6개월차 이후, 코어 5종 평균 ≥ 40, 팬 ≥ 3,000. 월 계획 화면의 "데뷔 평가 신청" 버튼으로 실행(그 달 슬롯과 별개, 즉시 판정).
- 점수 = 코어 5종 평균 + (비주얼 − 50)×0.2 + min(10, 팬/1,000) + rng(−5~+5).
- 통과: 점수 ≥ 50 → 데뷔 쇼케이스: 팬 += 15,000 + 점수×200, 평판 +5, `debuted=true`, `debutMonth`=현재 월, 다음 컴백 = 현재 월 + 4, 포트레이트 `rookie`.
- 실패: 스트레스 +15, 호감도 −2, `debutEvalFailures` +1. 재신청은 2개월 후 가능.
- 신청 자체의 스트레스 +10.
- **회사 최후통첩**: 18개월차에 안내 이벤트(E14). 24개월차 월말까지 미데뷔 → 엔딩 `contract_terminated`.

### 8.3 컴백 (데뷔 후 4개월마다)
`nextComebackMonth`의 월 계획 시작 전에 컴백 화면이 뜬다.
- 선택: 콘셉트 5종 중 1, 타이틀 포커스(보컬/댄스/랩) 중 1.
- 점수 = (0.45×포커스 능력치 + 0.25×코어 평균 + 0.15×비주얼 + 0.15×min(100, log10(팬+1)×12)) × 콘셉트 적성 × 자작곡 배수 + rng(−5~+5)
  - 자작곡 배수(E26 수락 시 1회): 포커스 능력치 ≥ 75면 ×1.15, 아니면 ×0.9.

| 결과 | 점수 | 팬 증가 | 자금 | 평판 | 비고 |
|---|---|---|---|---|---|
| `top1` 음원·음방 1위 | ≥ 85 | max(50,000, 팬×0.6) | +800 | +3 | `topRankCount` +1, CG `first_win`(최초 1회) |
| `top10` | 70~84 | max(20,000, 팬×0.3) | +400 | +1 | |
| `top50` | 55~69 | max(8,000, 팬×0.12) | +150 | 0 | |
| `fail` 차트 진입 실패 | < 55 | 팬 −5% | +30 | −2 | 스트레스 +10 |

- 결과 문구에 콘셉트 적성 힌트를 넣는다(적성 ≥ 1.1: "이 콘셉트, 하람에게 정말 잘 어울렸다", ≤ 0.9: "어딘가 어색하다는 반응").
- 컴백 후 2개월 동안 `music_show` 효과가 최대(activeMul 1.0).
- 마지막 컴백은 36개월차까지 허용.

### 8.4 연말 시상식 (12·24·36개월차 월말, 데뷔 상태일 때)

| 상 | 조건 | 효과 |
|---|---|---|
| `rookie` 신인상 | 데뷔 후 첫 시상식, 팬 ≥ 200,000 | 팬 +10%, 평판 +5, 호감도 +3 |
| `bonsang` 본상 | 팬 ≥ 1,000,000 | 팬 +10%, 자금 +300 |
| `daesang` 대상 | 팬 ≥ 3,000,000, 코어 평균 ≥ 80 | 팬 +15%, 자금 +1000, 평판 +10, CG `award_grand_prize` |
| `popularity` 인기상 | 해당 연도 `top1` 2회 이상 | 팬 +5% |

여러 상 동시 수상 가능. 아무 상도 없으면 "올해는 객석에서 박수만" 문구.

### 8.5 위기 규칙 (엔진 규칙, 이벤트와 별개)
- 평판 ≤ 10 → 즉시 엔딩 `scandal_fall`.
- 스트레스 = 100 → E31 발생. 호감도 ≥ 40이면 슬럼프(스트레스 50, 전 능력치 −3, 체력 최대치로), 미만이면 엔딩 `burnout_leave`.
- 체력 ≤ 0 → 그 주 활동 직후 E32 발생(활동 효과는 유지). E32 처리 후 스트레스가 100이면 곧바로 E31.

### 8.6 포트레이트 단계
- `trainee`: 데뷔 전
- `rookie`: 데뷔 후 ~ 페이즈 `rising` 전
- `star`: 페이즈 `rising` 이상

## 9. 이벤트 시스템

### 9.1 규칙
- 이벤트는 각 주차 활동이 끝난 직후 판정. 한 주에 최대 1개, 한 달에 최대 2개(고정 이벤트는 예외).
- 판정 순서: ① `fixed_month`(해당 월 1주차) ② `conditional`(조건 충족, 우선순위 높은 순) ③ `random`(chance/주, 조건 충족 후보 중 가중 랜덤).
- `once`인 이벤트는 회차당 1회. `cooldownMonths`는 재발 최소 간격.
- 선택지는 2~3개. 일부 선택지는 능력치 판정(`check`)으로 성공/실패가 갈린다.
- 텍스트 톤: 하람은 반존대("매니저님, 저 이거 해도 돼요?"), 나레이션은 담백한 3인칭. 이모지 금지.

## 10. 호감도와 대사

### 10.1 호감도 구간

| 구간 | 호칭/태도 |
|---|---|
| 0~29 | 사무적. "네." "알겠습니다." |
| 30~59 | 보통. 농담 조금. |
| 60~84 | 신뢰. 고민을 먼저 털어놓는다. |
| 85~100 | 가족 같은 사이. 비밀 엔딩 후보. |

### 10.2 월간 대사 (월말 리포트·월 계획 화면)
무드 = `stressed`(스트레스 ≥ 70) > `tired`(체력 < 30 또는 부상) > `bonded`(호감도 ≥ 70) > `happy`(이번 달 팬 +20% 이상 또는 컴백 top10 이상) > `neutral`.
페이즈(연습생/데뷔 후) × 무드 5종 = 10풀, 각 풀 6~8줄. 구현 시 `dialogue.ts`에 작성.

## 14. 밸런스 검증 시나리오 (구현 후 테스트/플레이로 확인)

| 시나리오 | 기대 결과 |
|---|---|
| 보컬 레슨 3 + 휴식 1만 반복 | 보컬은 오르지만 코어 5종 평균 40 미달로 데뷔 신청 불가 → 24개월차 계약 종료. 데뷔하려면 다른 코어도 최소한 올려야 한다 |
| 알바만 반복 | 자금은 늘지만 24개월차 `contract_terminated` |
| 휴식 없이 훈련만 4슬롯 | 3~4개월 내 체력 0 → E32, 스트레스 100 → E31 |
| 보컬 몰빵 + 발라드 컴백 | 36개월차 보컬 90 달성 가능 → `solo_vocalist` |
| 균형 성장 + SNS·음방 꾸준히 | 팬 100만 이상 도달 가능 → `top_idol` 이상 |
| 자유분방형 + SNS 과다 | 열애설·루머 빈발, 평판 관리 실패 시 `scandal_fall` 가능 |
